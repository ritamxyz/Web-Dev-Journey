## 📚 01. Course Practices

| Questions | Concepts Covered |
|---|---|
| Q1–Q3 | HTML structure, text elements, lists, hyperlinks and semantic elements |
| Q4–Q5 | Subscript, superscript and HTML entities |
| Q6 | Tables, captions, `rowspan` and `colspan` |
| Q7–Q9 | Forms, input types, selection controls and form submission |
| Q10 | Structured feedback forms, fieldsets and radio groups |

These exercises establish the foundational concepts used throughout the independent implementations.

## 🧱 02. Basics of HTML

**Directory:** `01-Basics-of-HTML/`

Five independent webpages developed by expanding the original course exercises into more detailed implementations.

| Implementation | Description |
|---|---|
| **Avengers — The Original Six** | An informational character dossier featuring six original Avengers, individual profiles, abilities and internal navigation. |
| **Guide to Common Fruits** | A nutritional reference featuring four fruits, individual profiles, images and health-related information. |
| **Basic Portfolio Page** | A resume-style personal webpage containing education, technical skills, interests and contact information. |
| **Basic Math Formulas** | A reference sheet containing 25 mathematical formulas covering algebraic identities and logarithmic properties. |
| **About Weather Today — Kolkata** | A dated weather-report webpage presenting temperatures, humidity, wind conditions and weather outlook. |

**Concepts explored:** Document structure, headings, paragraphs, lists, images, hyperlinks, internal navigation, text formatting, HTML entities, `<sup>` and `<sub>`.

## 📊 03. Tables in HTML

**Directory:** `02-Table-in-HTML/`

Four implementations exploring how HTML tables can represent structured academic, financial and examination information.

| Implementation | Description |
|---|---|
| **Student Information Table** | Student records with grouped headings and merged cells. |
| **College Timetable** | B.Tech first-semester weekly schedule with practical groups, course information and faculty details. |
| **E-Commerce Tax Invoice** | Sample retail invoice containing item descriptions, HSN/SAC codes, quantities, prices and GST calculations. |
| **JEE Main 2026 Scorecard** | Examination scorecard representation with candidate details, subject-wise scores and performance tables. |

**Concepts explored:** Table structure, captions, multiple header rows, `<thead>`, `<tbody>`, `<tfoot>`, `rowspan`, `colspan` and complex tabular layouts.

## 🚀 06. Final Mini-Projects

**Directory:** `05-Final-Mini-Projects/`

Three larger projects combining multiple HTML concepts into complete webpage experiences.

### 🏥 MediCare Plus

**Project Type:** Healthcare Information & Appointment Portal

A multi-specialty healthcare website concept based in Kolkata, featuring:

- Medical departments and doctor profiles.
- Hospital statistics and consultation fees.
- Doctor availability and appointment request forms.
- Diagnostic services and patient resources.
- Emergency information, policies and FAQs.

**Primary Focus:** Semantic structure, detailed forms, tables, input validation and organizing healthcare information.

### 🎓 TechFest 2026

**Project Type:** University Technology Festival Website

A university technology festival portal featuring:

- Festival introduction and event highlights.
- Featured speakers and event schedules.
- Technical competitions and project showcases.
- Registration form and important notices.
- Venue information, FAQs and contact details.

**Primary Focus:** Event-oriented content organization, schedules, tables, forms, embedded media and semantic elements.

### 💻 DevConnect 2026

**Project Type:** Developer Conference Website

A two-day developer conference website scheduled for **21–22 November 2026** at Science City Auditorium, Kolkata.

Major sections include:

- Conference introduction and highlights.
- Speaker profiles and technical sessions.
- Two-day conference schedule.
- Venue, transportation and visitor information.
- Detailed conference registration form.
- FAQs, policies and community information.

**Primary Focus:** Large-scale document organization, semantic HTML, interconnected sections, detailed forms and structured information.
