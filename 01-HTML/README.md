# 00 — 📖 Course Practices

**Directory:** `00-Course-Practices/`

This directory preserves the ten original practice questions completed alongside the HTML lectures in the Apna College Sigma Full Stack Web Development course.

Each question introduced or reinforced a particular HTML concept. The exercises were implemented individually, without replacing the original questions with their independently expanded versions.

### Practice Questions & Learning Outcomes

| Practice Question | Main Focus | What I Implemented & Learned |
|:---|:---|:---|
| **01 — Introducing the Basics of HTML** | Document structure and text elements | Created a basic Avengers webpage featuring Iron Man, Captain America and Hulk. Practised headings, paragraphs, text emphasis and the fundamental HTML document structure. |
| **02 — Introducing Lists in HTML** | Unordered lists and hyperlinks | Created a list of four fruits with individual links to their corresponding images. Practised `<ul>`, `<li>`, `<a>` and relative file paths. |
| **03 — HTML and HTML Semantics** | Semantic structure and content organization | Developed a humorous profile page for Daku Mangal Singh, containing Education, Skills, Hobbies and Contacts. Explored `<header>`, `<main>`, `<section>`, `<footer>`, lists, images and hyperlinks. |
| **04 — Introducing Subscript and Superscript** | Mathematical and chemical notation | Represented the Pythagoras theorem and glucose's chemical formula using `<sup>` and `<sub>`. |
| **05 — Introducing HTML Entities** | Special characters and character references | Displayed cloud and rain symbols alongside ordinary text. Practised named and numeric HTML entities, including `&amp;`, `&#9729;` and `&#9748;`. |
| **06 — Introducing Tables in HTML** | Tables, grouped headings and merged cells | Created a food menu containing items and prices in INR and USD, with a calculated total. Practised table sections, captions, `rowspan` and `colspan`. |
| **07 — Introducing Forms in HTML** | Basic form controls | Created a username and password form with Submit and Reset buttons. Worked with labels, input types, placeholders and button types. |
| **08 — Redirecting Form** | Form submission and external redirection | Built separate Google and YouTube search forms. Explored form actions, query parameter names, submission and opening results in a new browser tab. |
| **09 — Basic Registration Form** | Input types and selection controls | Created a registration form with first name, last name, gender selection and a terms-of-service checkbox. Practised dropdown options and checkbox controls. |
| **10 — Feedback Form** | Structured forms and user responses | Developed a feedback form with name, email, message and a five-point rating system. Practised `<fieldset>`, `<legend>`, `<textarea>` and radio-button groups. |

### Concepts covered

These exercises provided the initial hands-on exposure to:

- HTML document structure and content elements.
- Lists, images and hyperlinks.
- Semantic elements and document sections.
- Subscript, superscript and HTML entities.
- Tabular data and cell merging.
- Forms, input types and selection controls.
- Form submission and external search redirection.

### 01. Avengers — The Original Six

**File:** `01-Basic-Avengers-Webpage.html`

An expanded informational webpage dedicated to the original six Avengers from the Marvel Cinematic Universe.

What began as a simple heading-and-paragraph exercise eventually became a detailed character dossier presented through a fictional S.H.I.E.L.D. archive format.

The webpage includes:

- An introductory section covering the Avengers Initiative.
- A table of contents with links to individual sections.
- Dedicated profiles for Iron Man, Captain America, Thor, Hulk, Black Widow and Hawkeye.
- Character backgrounds, abilities, equipment and notable quotes.

# 🎯 What This HTML Phase Represents

Looking across the entire directory, the work can be understood in three stages.

### 1. Understanding Individual Concepts

The ten course exercises introduced different HTML elements and their behaviour.

I preserved these original exercises to maintain a record of the actual coursework completed during the lectures.

### 2. Exploring Beyond the Original Questions

The independent implementations took individual concepts further.

A simple list became a fruit guide. A heading exercise became an Avengers dossier. A mathematical formatting question became a reference sheet. A basic table evolved into an academic timetable and an invoice.

The same approach continued with forms and semantic document structures.

### 3. Combining Concepts into Larger Implementations

The three final mini-projects brought different HTML concepts together:

| Project | Type | Primary Focus |
|:---|:---|:---|
| MediCare Plus | Healthcare Portal | Medical information, appointment forms and patient resources |
| TechFest 2026 | University Event Website | Event schedules, competitions, speakers and registration |
| DevConnect 2026 | Developer Conference Website | Conference programme, detailed registration and visitor information |

These projects represent the point where individual HTML elements started working together to form more complete webpage experiences.
