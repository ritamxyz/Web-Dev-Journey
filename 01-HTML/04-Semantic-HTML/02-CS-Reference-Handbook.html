1. Asymptotic Notations

Asymptotic analysis defines the mathematical bounds of an algorithm's runtime relative to input growth rate n.

  • Big-O (Ο): Tight asymptotic upper bound. Represents the worst-case ceiling: f(n) ≤ c · g(n).
  • Big-Omega (Ω): Asymptotic lower bound. Represents guaranteed best-case execution: f(n) ≥ c · g(n).
  • Big-Theta (Θ): Asymptotically tight bound where upper and lower growth match.

3. Canonical Implementation: Binary Search (C++)

Prerequisite: The underlying container must be indexed randomly and sorted in ascending order.

int binarySearch(const int arr[], int low, int high, int key) {
    while (low <= high) {
        int mid = low + (high - low) / 2; // Avoids integer overflow
        if (arr[mid] == key)
            return mid; // Target index discovered
        else if (arr[mid] < key)
            low = mid + 1;
        else
            high = mid - 1;
    }
    return -1; // Target not present
}
