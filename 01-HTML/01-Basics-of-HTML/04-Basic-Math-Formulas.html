BASIC MATH FORMULAS: ALGEBRA AND LOGARITHMS

A quick reference list of 25 foundational algebraic identities, polynomial expansions, and logarithmic laws.

Algebraic Identities & Expansions

  1. Square of a Sum: (a + b)2 = a2 + 2ab + b2
  2. Square of a Difference: (a - b)2 = a2 - 2ab + b2
  3. Difference of Two Squares: a2 - b2 = (a - b)(a + b)
  4. Sum and Difference Identity 1: (a + b)2 + (a - b)2 = 2(a2 + b2)
  5. Sum and Difference Identity 2: (a + b)2 - (a - b)2 = 4ab
  6. Binomial Product with Common Term: (x + a)(x + b) = x2 + (a + b)x + ab
  7. Square of a Trinomial: (a + b + c)2 = a2 + b2 + c2 + 2ab + 2bc + 2ca
  8. Cube of a Sum: (a + b)3 = a3 + 3a2b + 3ab2 + b3 = a3 + b3 + 3ab(a + b)
  9. Cube of a Difference: (a - b)3 = a3 - 3a2b + 3ab2 - b3 = a3 - b3 - 3ab(a - b)
  10. Sum of Two Cubes: a3 + b3 = (a + b)(a2 - ab + b2)
  11. Difference of Two Cubes: a3 - b3 = (a - b)(a2 + ab + b2)
  12. Sum of Three Cubes Identity: a3 + b3 + c3 - 3abc = (a + b + c)(a2 + b2 + c2 - ab - bc - ca)
  13. Conditional Cubic Property: If a + b + c = 0, then a3 + b3 + c3 = 3abc
  14. Quadratic Discriminant: D = b2 - 4ac
  15. Quadratic Formula: x = (-b ± √(b2 - 4ac)) / (2a)

Laws and Properties of Logarithms

  1. Product Rule: logb(xy) = logb(x) + logb(y)
  2. Quotient Rule: logb(x / y) = logb(x) - logb(y)
  3. Power Rule: logb(xk) = k · logb(x)
  4. Base-to-Power Rule: logbk(x) = (1 / k) · logb(x)
  5. Logarithm of Base: logb(b) = 1
  6. Logarithm of One: logb(1) = 0
  7. Change of Base Formula: logb(a) = logc(a) / logc(b)
  8. Reciprocal Base Property: logb(a) = 1 / loga(b)
  9. Exponential-Log Cancellation: blogb(x) = x
  10. Power-Base Swap Rule: alogb(c) = clogb(a)
