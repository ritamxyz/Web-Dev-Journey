Progressive exercises moving from inline/internal/external CSS rules to complex multi-tier dropdown navbars, CSS Grid alignment matrices, and preloader animations.

Concept Progression Roadmap

Practice Range Core Module Topics & Implementations Practised
Q01–Q02 Foundations & Colours Inline, internal & external CSS, named/hex/rgb colours, Ozymandias poem typography
Q03–Q04 Selectors & Combinators Universal, element, ID, class, descendant, child (>), adjacent sibling (+) & attribute selectors
Q05–Q06 Typography & Pseudo-Selectors Tony Stark MCU wiki layout, :hover, :active, :focus, :checked, :nth-child, ::first-letter, ::selection
Q07–Q08 Box Model & Traffic Light Width, height, padding, asymmetric border-radius, margins & complete Traffic Light UI component

Q15–Q18 CSS Grid System repeat(), fr units, track spanning, justify-items, align-items, place-items & place-self
Q19–Q20 Keyframes & Pet Adoption UI Multi-step @keyframes border cycling, spinning preloader overlay & responsive Pet Adoption page

🎯 Learning Approach

5-Stage Iterative Workflow

Every concept in this repository followed a structured progression from theory to polished implementation.

01

📖 Learn

Understand core CSS specifications, visual formatting models, and layout behaviours through lectures and documentation.

02

💻 Practise

Solve targeted single-concept exercises (Q01–Q20) independently to test selector and property mastery.

03

🏗️ Build

Combine multiple layout systems (Grid + Flexbox + Positioning) into complete standalone projects.

04

🔍 Review

Inspect box dimensions, responsive breakpoints, overflow edge cases, and stylesheet modularity.

05

🔧 Improve

Refine transitions, fix viewport overflow issues, and polish visual hierarchy across desktop and mobile screens.
